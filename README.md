# tradingbot

Recherche et backtests pour un futur bot de trading automatisé (MoonX ou MT5).

L'ancien bot (backend FastAPI, app Expo, passerelle MT5, copieur Telegram) a été retiré ; il reste disponible dans l'historique git.

- `scripts/hedge_backtest/` : backtests (hedge, or/argent, trend following multi-actifs). Voir son README.
- `scripts/news_filter/` : filtre de news avec Jev (TypeSafe). Voir son README.
- `monteur-ia/` : kit pour monter ses vidéos avec Claude Code (dossiers, installation, prompts). Voir son README.
